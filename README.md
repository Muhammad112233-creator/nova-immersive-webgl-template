# NOVA — Immersive WebGL Scroll Template

An immersive, scroll-driven WebGL storytelling template. Five chapters, cinematic
transitions, a draw-to-enter gate, custom cursor, procedural audio and a full HUD —
all original artwork, copy and sound, ready to rebrand.

**Everything is placeholder branding on purpose.** Change the strings in one config
file, drop in your own images, and it becomes your site.

---

## Quick start

```bash
npm install
npm run dev      # http://localhost:5173
```

| Script            | What it does                                                 |
| ----------------- | ------------------------------------------------------------ |
| `npm run dev`     | Start the Vite dev server with hot reload                    |
| `npm run build`   | Production build into `dist/`                                |
| `npm run preview` | Serve the production build locally                           |
| `npm run assets`  | Regenerate every image/audio asset (needs Python 3 + Pillow) |

Requirements: **Node 18+** and a browser with **WebGL 2**.

## What the experience does

The whole site is a single canvas. There is no scrolling DOM — the scroll wheel
drives a virtual timeline of **1368vh** split into nine segments:

| #   | Segment    | Length | Type                                      |
| --- | ---------- | ------ | ----------------------------------------- |
| 1   | `gate0to1` | 50vh   | Auto (3.5s) — frost spreads to a whiteout |
| 2   | `stage1`   | 175vh  | Scrub — slow dolly, the opening line      |
| 3   | `gate1to2` | 50vh   | Auto (3.0s) — the form shatters           |
| 4   | `stage2`   | 250vh  | Scrub — drifting petals, camera sway      |
| 5   | `stage3`   | 325vh  | Scrub — flight through a violet field     |
| 6   | `gate3to4` | 50vh   | Auto (3.0s) — tunnel fly-through to white |
| 7   | `stage4`   | 368vh  | Scrub — the globe rises and reveals       |
| 8   | `gate4to5` | 50vh   | Auto (0.6s) — short whoosh                |
| 9   | `stage5`   | 50vh   | Interactive — pick a destination          |

Before any of it starts, the loader counts down from 99 and the visitor has to
**draw a circle** to enter. Completing the circle unlocks the scroll, starts the
ambience, and awards the first 25 XP.

**Stage 5** is free-look: drag the joystick or use the D-pad to orbit and zoom
the globe, hover a marker to open its card.

## Rebranding it

### 1. Text, colours and structure — `src/core/config.js`

This one file is the source of truth for the entire experience:

```js
export const BRAND = {
  name: "NOVA",
  tagline: "An immersive scroll-driven WebGL template",
  url: "https://example.github.io/nova-immersive-webgl-template/",
  menu: [
    /* ... */
  ],
};
```

| Export         | Controls                                                 |
| -------------- | -------------------------------------------------------- |
| `BRAND`        | Name, tagline, canonical URL, menu items                 |
| `GRADIENT`     | The seven-stop radial gradient behind everything         |
| `COLORS`       | Deep / mid / light / accent / warm / ink palette         |
| `SEGMENTS`     | Segment order, lengths and gate timings                  |
| `STAGE_TEXT`   | The narrative lines drawn on canvas                      |
| `STAGE_STATUS` | The HUD status label per stage                           |
| `MARKERS`      | The four globe markers and their cards                   |
| `STAGE_THEME`  | Per-stage tint and HUD colour mode                       |
| `AUDIO_BEDS`   | Which ambience plays in which stage                      |
| `QUALITY`      | Low / medium / high tiers (pixel ratio, particle counts) |

Change the palette in `COLORS` **and** `GRADIENT` together — the WebGL background
reads `GRADIENT` directly, while the HUD reads the CSS variables in `src/style.css`.

### 2. Images and audio — `tools/gen_assets.py`

Every asset in `public/assets/` is generated by this script — nothing is
hand-drawn or licensed from anywhere. Edit the palette constants at the top and
re-run it:

```bash
pip install pillow
npm run assets
```

Or just delete the folder and drop in your own files with the same names. The
manifest lives in `src/core/config.js`.

- `brand/` — logo, favicons, OG image
- `ui/` — cursor atlas, XP star, marker cards, share poster
- `textures/` — frost, matcaps, particle atlas, backdrops, world map
- `audio/` — five ambient beds and ten one-shots

### 3. Fonts — `index.html`

Four Google fonts are linked in the head and exposed as CSS variables in
`src/style.css`: `--mono` (Space Mono), `--sans` (Inter), `--serif` (Newsreader)
and `--script` (Caveat). Swap the links and the variables together.

```

  style.css             All HUD and interface chrome
  core/
    config.js           Single source of truth — start here
    ScrollManager.js    Virtual scroll with easing
    MasterTimeline.js   Segment sequencing and gate autoplay
    AudioEngine.js      WebAudio beds, one-shots, gesture unlock
  passes/
    shaders.js          All GLSL
    Composer.js         Ping-pong post chain
    Objects.js          Cursor orb, shatter form, tunnel, globe
    Particles.js        Instanced particle field
    TextLayer.js        Narrative type baked to a canvas texture
  stages/
    stages.js           The nine segment implementations
    markers.js          Globe markers and stage 5 controls
  ui/
    Loader.js           99 → 0 countdown and logo morph

    cursor.js           Custom cursor atlas
```

### Render pipeline

Passes run in this order, ping-ponging between two render targets:

```
bgPass → scenePass → textPass → frostPass → lensBlurPass → fgPass
```

`renderer.autoClear` is **false** — each pass clears explicitly. If you add a
pass, keep it that way or earlier passes get wiped.

## Performance

Quality tiers are picked automatically from `navigator.deviceMemory`,
`hardwareConcurrency` and whether the pointer is coarse. Touch devices get the
`LOW` tier: reduced pixel ratio, fewer particles, and the cursor orb is skipped
entirely. Tune the tiers in `QUALITY` in `src/core/config.js`.

---

## Accessibility and fallbacks

- `<noscript>` message for JavaScript-off visitors.
- Audio never autoplays; it waits for a gesture and can be muted from the HUD.
- The custom cursor is disabled on touch devices, where the native one returns.
- Modals trap focus and close on <kbd>Esc</kbd>.
